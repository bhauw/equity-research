# Archetypes, Valuation Methods, Gates & Sizing

## Step Zero — the six archetypes

Classification selects the **valuation method only**. All 8 lenses run regardless.

| Archetype | Characteristics |
|---|---|
| Quality Compounder | High ROIC, durable moat, reinvestment runway, low cyclicality |
| Growth Accelerator | Revenue growth > 20%, expanding TAM, operating leverage building |
| Deep Value / Cigar Butt | Below asset value or trough earnings; no near-term catalyst needed |
| Turnaround / Special Situation | Operational fix, mgmt change, spin-off, or balance-sheet repair underway |
| Cyclical / Commodity | Earnings driven by macro cycle, commodity prices, or credit conditions |
| Macro / Rate Sensitive | Banks, REITs, infrastructure — driven by rate & liquidity regime |

For each archetype state: fits? (Yes / Partially / No) · key evidence for and against ·
final classification with confidence (High/Medium/Low) · hybrid flag if applicable.

## Primary valuation method by archetype

| Archetype | Primary method |
|---|---|
| Quality Compounder | 10-year DCF + ROIC-based terminal value |
| Growth Accelerator | DCF with stage-gate revenue model + EV/Revenue exit multiple |
| Deep Value / Cigar Butt | Asset value (liquidation + replacement) + earnings power value |
| Turnaround | Normalized-earnings DCF + sum-of-parts for hidden assets |
| Cyclical / Commodity | Mid-cycle earnings DCF + EV/EBITDA at trough/peak/mid |
| Macro / Rate Sensitive | Dividend discount model + book value + ROE vs cost of equity |

## Investment gates — flat, all archetypes

| Gate | What to assess |
|---|---|
| Downside protection | Credible floor: asset value, earnings power, or bear-case IV > current price |
| Balance sheet resilience | Survives a 25–30% revenue or EBITDA decline without existential stress |
| Competitive stability | Not in structural decline — position stable, improving, or recoverable |
| Return adequacy | Expected IRR ≥ 10% base case; ≥ 15% bull case at current price |
| Thesis legibility | Core case statable clearly in 2–3 sentences |
| Lens coverage | ≥ 5 of 8 lenses bullish or neutral |

The lens gate counts all 8 equally — not the "most relevant" ones. Buffett + Klarman bullish
while the other six are bearish is a 2/8, and that is informative.

## Position sizing — lens-count driven

| Lens map + gate result | Sizing |
|---|---|
| All 6 gates passed; ≥ 6 of 8 lenses bullish | Full position — high conviction |
| All 6 gates passed; 4–5 lenses bullish | Half position — add on confirmation |
| 5 of 6 gates; 3–4 lenses bullish; one gate borderline | Starter or watchlist — wait for clarity |
| Any gate failed, or < 3 lenses bullish | Do not invest — redirect research time |

## Universal thresholds — Quality Compounders only

Reference points, not universal requirements. A deep-value name at 8% ROIC trading at 50c on the
dollar of asset value can be an equally excellent investment; the gates above are the universal test.

| Metric | Target |
|---|---|
| ROIC | > 15% sustained; ROIC − WACC spread > 5% |
| ROE | > 20% across a full cycle |
| Revenue CAGR | ≥ 10% with stable or expanding margins |
| FCF conversion | FCF / EBITDA > 70% |
| Net Debt / EBITDA | < 3.0x (< 2.0x for cyclicals) |
| Interest coverage | > 5.0x |
| Margin of safety | Base-case intrinsic ≥ 20% above price |
| Monte Carlo P(upside) | > 60% |
| Expected IRR (base) | ≥ 15% at current price |
